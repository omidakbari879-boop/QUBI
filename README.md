# QUBI

QUBI ist ein moderner KI-Assistent mit Gemini-Backend.

## Cloudflare

1. Repository mit Cloudflare Workers verbinden.
2. Unter **Settings → Variables and Secrets** ein Secret namens **GEMINI_API_KEY** anlegen.
3. Als Wert den eigenen Gemini API-Key eintragen.
4. Deployment starten.

Der API-Key gehört niemals in dieses Repository oder in den Browser-Code.
